To generate new rules, run `python build_data.py` while in `Data` (same directory as this README).
The required data is provided in the form of .csv files. They should be added to the `templates` directory.
The required .csv files are
```
moon_access.csv
logic_tokens.csv
logic_nodes.csv
route_edges.csv
entrance_links.csv
```

The generated data will be placed in the `generated` directory
